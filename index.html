線上編輯

連上你的 GitHub 之後，就可以直接在這個畫面新增、修改、刪除作品，圖片拖進來就會自動壓縮上傳，不用再改檔案。

  1. 到 GitHub 金鑰申請頁（會要你登入）
  2. Token name 隨便取，例如 作品牆
  3. Expiration 選一個到期日，例如 1 年
  4. Repository access 選 Only select repositories，勾你的作品牆倉庫
  5. Permissions → Repository permissions 裡找到 Contents，改成 Read and write
  6. 按最下面的 Generate token，把那串 github_pat_… 複製下來貼到下面

關於這把金鑰：它只存在你這台電腦的瀏覽器裡，不會寫進網頁檔案，訪客看不到也拿不到。但它等同於你對這個倉庫的寫入權限，所以不要貼給別人、不要在公用電腦上勾「記住」。真的外流了，回 GitHub 把它刪掉就立刻失效。
